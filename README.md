## About the Portfolio

The site presents Shrishti’s background, skills, experience, and selected work in a responsive, teal-and-white design. An animated 3D avatar changes pose as visitors move through the page, with reduced-motion preferences respected.

## Run Locally

### Requirements

- Node.js `^20.19.0` or `>=22.12.0`
- npm

### Setup

```bash
git clone https://github.com/Shrishti1701/portfolio.git
cd portfolio
npm ci
npm run dev
```

Vite prints the local development URL in the terminal.

## Production Build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. For Vercel, use the **Vite** framework preset, build command `npm run build`, and output directory `dist`.
